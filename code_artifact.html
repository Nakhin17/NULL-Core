Escrow Workflow System

ขั้นตอนและบริการคนกลาง NULL CORE

ธุรกรรมของคุณจะปลอดภัยและสามารถส่งมอบทรัพย์สินดิจิทัลได้อย่างไร้กังวล ภายใต้การควบคุมของแอดมินคนกลาง

1

ผู้ซื้อชำระเงิน

ผู้ทำการกดซื้อสินค้าที่ต้องการ เงินประกันจะถูกส่งไปเก็บไว้ที่ระบบคนกลางของแอดมิน (Wallet Escrow Pool)

2

ระบบเข้าถือครองบัญชี

แอดมินคนกลางจะทำหน้าที่สแกนตรวจสอบความปลอดภัยตัวตน สกัดกั้นไอดีที่ติดสัญญากู้ยืม หรือผูกมัดอันตราย

3

ตรวจสอบและรับมอบ

ผู้ซื้อทำการรับข้อมูลล็อกอินไปทดสอบเปลี่ยนพาสเวิร์ดผูกเบอร์ให้เรียบร้อย และกลับมาปุ่มกดยืนยันการซื้อขาย

4

ส่งมอบรายได้แก่ผู้ขาย

เงินจะทำการโอนเข้าสู้บัญชีกระเป๋าตังค์ (Wallet) ของผู้ฝากขายทันที โดยหักเพียงค่าธรรมเนียมกลาง 5% เท่านั้น
